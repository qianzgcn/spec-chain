# 测试数据安全

- 用例运行前已经存在的全部数据都是受保护的业务基线，包括项目变量代表的账号和数据。
- 既有数据只可用于登录、查询、只读选择和断言，不得修改、删除、归档、禁用、绑定、解绑或消费。
- 新增、编辑、删除、状态变化等写操作，只能作用于本次脚本运行时生成的唯一临时数据。
- 临时标识必须在运行时生成，不得使用固定名称或项目变量中的值，也不得与既有数据同名。
- 写操作脚本必须使用 `try/finally`，并在 finally 中只清理本次创建的数据；断言失败也必须执行清理。
- 编辑、删除或状态变化场景必须先创建临时对象，再对该对象执行目标操作。
- 无法安全创建、识别或清理临时数据时，不生成脚本，明确报告缺少的前置条件和建议补充内容。
