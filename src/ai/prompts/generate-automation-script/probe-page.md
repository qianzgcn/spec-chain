# 真实页面探测

1. 从 Base URL 或其同源路径开始，先获取页面快照，再引用最新快照中的元素编号进行交互。
2. 页面发生导航、弹窗开关或大幅变化后重新获取快照；元素编号失效时重新快照，不得绕过探测猜测 locator。
3. 可以使用页面查找缩小大型快照范围，并使用 locator 生成工具确认关键控件的稳定定位方式。
4. locator 优先级为 `getByTestId`、`getByRole`、`getByLabel`、`getByPlaceholder`、`getByText`。只有语义定位不可用时才允许使用简洁且稳定的 CSS。
5. 每个操作和断言必须有明确作用域：弹窗先限定 dialog，表格先限定目标行，表单先限定相应表单区域。
6. 不依赖坐标、按钮位置、视觉顺序、临时 class、构建产物 class 或当前布局。
7. 探测阶段只做理解流程所需的最少交互。探测会话由平台强制阻断非 GET/HEAD/OPTIONS 请求，因此不得尝试提交、创建、编辑、删除或改变业务状态；如果必须执行写操作才能确认流程，应调用 `reportFailure`。
8. 只允许导航到 Base URL 的同源地址。遇到第三方登录或跨域流程时停止，并报告缺少可安全执行的同源入口。
9. 任务声明已使用账号对象预登录时，当前探测会话已经由平台登录；不得返回登录页重新探测登录流程，也不得在最终脚本中复制登录定位。
